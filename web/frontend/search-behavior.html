    METHOD

    判定口径

    查询相似度归一化后比较 token Jaccard。完全相同为「完全重复」，≥ 0.75 为「近重复」，0.30–0.75 为「逐步拓展」，< 0.30 为「新方向」。

    行为判定首条查询不计入重复率。重复 ≥ 45% 且新方向 < 35% 为「反复追问」；重复 < 30% 且拓展 + 新方向 ≥ 70% 为「持续拓展」；其余为「混合迭代」。

    数据范围来自 Quest trace viewer 的搜索快照，仅保留 query、轮次、结果数、耗时与分类；不包含思考过程、网页正文和答案内容。

    读图提示相似度是启发式近似，不代表语义完全等价；把阈值与具体 query 放在一起看，比只看标签更可靠。
