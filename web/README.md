# QUEST 轨迹查看器

从仓库根目录运行 `workspace/env/bin/python web/serve.py`，然后在本机打开 `http://127.0.0.1:6080/trace-viewer-zh/`。远程服务器需要本机 SSH 端口转发；仅本地绑定时不会自动开放公网。

中英文静态页面位于 `trace-viewer/` 和 `trace-viewer-zh/`；工作区清单与轨迹 JSON 在 `trace-viewer/datasets/`。这两类数据、`trace-viewer-runtime/` 的服务日志和二进制均为本机数据，不提交 Git。中文路径使用相对符号链接，复制项目时请保留该链接。

浏览器每 5 秒检查选中数据和工作区清单，标签页不可见时暂停检查，重新可见后立即检查；请求失败时保留当前画面。只有后台生成器实际更新了数据文件才会看到新结果。单次数据变化会重新绘制当前轨迹并尽力保持当前任务、选项卡、已展开事件和滚动位置；页面不会自动运行任务。

旧 SFT GAIA 32 题的历史生成器位于 `workspace/strict-reproduction/gaia-sft10pct-32-20261028-r1/scripts/viewer_watch.py`，其输入与输出固定到当次实验。其他数据集必须使用相应生成器并在工作区清单中注册，不可把旧评分覆盖成新运行结果。此前评估已停止，需用户另行授权才可重新启动。

终止任务的显示状态记录在工作区清单的 `lifecycleOverride` 中；这只是展示层标记，不改原始轨迹或分数。恢复或新建运行时应登记新的工作区，不能把旧终止状态直接当作新结果。

通用 GAIA 视图生成器 `web/build_gaia.py` 读取指定运行的状态和跨度日志，默认拒绝覆盖现有轨迹文件。对终止的部分任务，可同时指定 `--include-running --stopped-at <UTC epoch>`；这时未完成任务的时长仅为最后一条已记录事件之前的窗口，并非包含暂停时间的执行耗时。生成器不会调用模型或评分器；通过及未评分状态来自输入记录。

工作区切换菜单按“目录 → 评估工作区”两级显示，二级目录默认收起。目录标题右侧显示“通过任务数 / 总任务数”；展开后，每个运行卡片右下角显示通过、进行中、未通过/异常三个状态点及数量。状态统计由 `serve.py` 的 `/api/workspace-status` 接口读取各数据集生成；若用纯静态服务器打开页面，状态数字会隐藏，其余功能不受影响。

目录标题可折叠；用“新建目录”创建目录，把工作区拖到目录可移动。悬停目录或工作区后点击右侧的 `⋯`，可以在 Codex 风格的操作菜单中打开工作区、重命名或收起目录；重命名在行内完成，Enter 保存，Esc 取消。目录、移动位置、显示名称和展开状态保存在当前浏览器的 localStorage；不会修改原始数据文件或数据集 ID，也不会自动同步到其他浏览器。清除浏览器站点数据会重置这些自定义设置。
